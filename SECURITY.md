# Security policy

## Reporting

- **Gameplay bugs:** Use the [bug-report form](https://github.com/PeytonBlakeslee/OmniMovement/issues/new/choose). Include reproduction steps and relevant versions, but redact personal information.
- **Potential security vulnerabilities:** If this repository is public and GitHub's **Report a vulnerability** option is enabled under **Security → Advisories**, use it to report details privately. This option is not available merely because a `SECURITY.md` file exists.
- **If private reporting is unavailable:** Open a nonsensitive [issue](https://github.com/PeytonBlakeslee/OmniMovement/issues/new/choose) asking to arrange a private contact method. Do **not** include an exploit, credential, sensitive file, or proof-of-concept details in that issue. Existing collaborators may use an established private channel instead.

Never post secrets, private paths, save files, full crash dumps, or identifying log details in a public issue.

## Downloads and scope

Only trust release packages distributed through this project's official channels and matched to their documented sources. A GitHub-generated source archive is not an installable Player ZIP; unverified third-party compiled binaries should not be treated as official releases.

This is an unofficial game mod, not a security or anti-cheat product. No fixed security-response deadline or commercial support guarantee is offered.
